# homebrew-unleash

Tap for the patched [unleash](https://github.com/rodion-gudz/unleash) — a fork of
[mateussiqueira/unleash](https://github.com/mateussiqueira/unleash) with critical fixes.

## Install

    brew tap rodion-gudz/unleash
    brew install rodion-gudz/unleash/unleash

## Update

    brew update && brew upgrade unleash
